# Солнечная Долина · «Крым, написанный великими»

Главная страница сайта винодельни «Солнечная Долина» (имение Архадерессе, 1888): рельеф Крыма, восход, дорога по полотнам Айвазовского, Куинджи, Коровина, Богаевского и Боссоли к долине.

- `krym/index.html` — версия со сценами дома (Капсель, овраг, урожай, подвал, ворота, дом 1888).
- `krym/originals.html` — версия только по полотнам мастеров и фотографии виноградников.

Управление: колесо или свайп — движение по дороге; клик по году внизу — переход к главе; «Звук» и «Музыка» в шапке; карточка «Это место сегодня» — фотография того же места (клик — шторка).

Все картины — общественное достояние, репродукции с Викисклада; фотографии Архадерессе — съёмка «Солнечной Долины», 21 августа 2026; остальные фотографии — Викисклад, авторы и лицензии в подвале страницы.
